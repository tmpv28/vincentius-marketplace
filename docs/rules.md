# Rules

TV-STANDARD installs as `~/.claude/rules/tv/`: a core that loads in every session, plus packs that
load in full the first time a file matching their `paths:` is read. Creating a file does not load
its pack, which is why the core says to read a matching file first. Generated by the Phase 3
migration; docs/coverage.md lists every section.

## Packs

| Pack | Loads when a file matching one of these is read |
| --- | --- |
| core | always |
| typescript | `**/*.ts`, `**/*.tsx`, `**/*.mts`, `**/*.cts` |
| react | `**/*.tsx`, `**/*.jsx` |
| accessibility | `**/*.tsx`, `**/*.jsx`, `**/*.html`, `**/*.htm`, `**/*.vue`, `**/*.svelte` |
| styles | `**/*.scss`, `**/*.css` |
| scss | `**/*.scss` |
| testing | `**/*.test.*`, `**/*.spec.*`, `**/vite.config.*`, `**/vitest.config.*`, `**/vitest.setup.*` |
| node-tooling | `**/package.json`, `**/pnpm-workspace.yaml`, `**/eslint.config.*`, `**/.prettierrc*`, `**/prettier.config.*`, `**/.stylelintrc*`, `**/stylelint.config.*`, `**/.lintstagedrc*`, `**/.husky/**`, `**/tsconfig*.json`, `**/vite.config.*` |
